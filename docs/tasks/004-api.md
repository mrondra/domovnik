# 004 – apps/api (NestJS 11)

Reference: ADR 0002, 0007, 0009; engineering.md §5, §9; zadání kap. 9.

Pozn. k ADR 0009: importy jsou bezpříponové, takže `apps/api` neběží v Node bez bundle kroku – v devu `tsx`, pro produkci bundle (esbuild/tsup).

## Cíl

Tenký bootstrap: auth, request kontext, auto-registrace feature modulů, mapování chyb, health. Žádná business logika.

## Rozsah

1. NestJS 11, Fastify adapter, `main.ts` s `loadEnv()`, pino logger, graceful shutdown.
2. `RequestContextMiddleware`: z session cookie / `Authorization: Bearer <api token>` / podepsaného odkazu vytvoří `RequestContext`, uloží do AsyncLocalStorage. Bez identity → 401 (kromě `/health`, `/auth/login`).
3. Auth modul: `POST /auth/login` (email+heslo → session cookie, httpOnly, SameSite=Lax), `POST /auth/logout`, `GET /auth/me`. Guards: `@Roles()`, `@RequireSvjAccess()`.
4. `FeatureModulesLoader`: importuje `packages/features/*/api/*.module.ts` podle konvence (generovaný barrel, commitovaný, stejný mechanismus jako 003).
5. Globální exception filter: taxonomie kernelu → HTTP; zod → 400 s detaily; neznámé → 500 bez detailu, log error s correlationId. Response vždy `{ error: { code, message, details?, correlationId } }`.
6. `GET /health` (db ping), OpenAPI přes `@nestjs/swagger` z DTO (zod → openapi přes `nestjs-zod` nebo ekvivalent; zvol, zdokumentuj).
7. Approvals endpoints (kernel entita, ale HTTP je tady): `GET /approvals` (inbox pro aktéra), `POST /approvals/:id/decide`. Signed link: `GET /a/:token` vrací data pro stránku (neschvaluje), `POST /a/:token/decide`.
8. API tokens endpoints: `POST /api-tokens` (vrací plaintext jednou), `GET`, `DELETE /:id`, výběr `allowedTools` z registru filtrovaného oprávněními uživatele.

## Akceptační kritéria

- e2e testy (supertest, testcontainer): login → me; cizí tenant nevidí approvals; GET na signed link nic nemění, POST rozhodne; API token s omezenými tooly odmítne volání nepovoleného toolu; revokovaný token → 401.
- Error filter: `DomainError` → 422, `NotFound` → 404, `Forbidden` → 403, zod → 400 (testy).
- Žádný import z vnitřku feature (depcruise zelený).
