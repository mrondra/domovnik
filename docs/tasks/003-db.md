# 003 – packages/db

Reference: ADR 0003, engineering.md §8.

## Cíl

Skládání drizzle schémat ze všech features, migrace, seed runner.

## Rozsah

1. `src/schema.ts` – auto-import `packages/kernel/src/db/schema.ts` + `packages/features/*/schema.ts` (generovaný soubor nebo glob přes `import.meta.glob`-ekvivalent v tsx; zvol deterministicky, výstup commitovaný).
2. `drizzle.config.ts`, `pnpm db:generate` (Drizzle Kit) + post-krok, který k migraci připojí `rlsPoliciesSql()` pro nové tabulky a `CREATE EXTENSION IF NOT EXISTS vector`.
3. `pnpm db:migrate` (Drizzle migrator, přes `withSystem`).
4. Seed runner: načte `packages/features/*/seed/index.ts` + kernel seed (tenant „Demo správa s.r.o.", uživatelé pro role, agentní identity), spouští v pořadí podle deklarovaných závislostí, idempotentně. Zatím jen kernel seed.
5. Test: migrace na čistý testcontainer projde, každá tabulka s `tenant_id` má RLS enabled a policy (dotaz do `pg_policies` – automatický test pro všechny budoucí tabulky).

## Akceptační kritéria

- `pnpm db:migrate && pnpm db:seed` opakovaně bez chyby.
- Test „every tenant table has RLS" prochází a selže, když záměrně přidáš tabulku bez `tenantTable()`.
